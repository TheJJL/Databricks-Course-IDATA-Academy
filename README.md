# Lumi Commerce Lakehouse

Proyecto práctico de capacitación Databricks.

## Casos del curso

1. **Lumi Commerce Lakehouse**
   - Lakehouse
   - Arquitectura Medallion
   - Delta Lake
   - SQL
   - KPIs
   - Dashboards

2. **Lluvia, Caña y Bagazo**
   - Caso espejo empresarial
   - EDA
   - Correlación
   - Feature engineering
   - MLflow
   - Batch inference
   - MLOps

## Principios del proyecto

- Código versionado.
- Notebooks organizados.
- Separación entre datos, código, SQL, documentación y entregables.
- Enfoque educativo en Databricks Free Edition.
- Explicación de escalamiento a Azure Databricks empresarial.

### ¿Qué espero aprender de Databricks?
1. Aprender a estructurar correctamente proyectos en Databricks.
2. Comprender e implementar una arquitectura Lakehouse con enfoque Medallion.
3. Aplicar las mejores prácticas actuales de la industria en ingeniería de datos, analítica y machine learning.
4. Trabajar con Delta Lake, SQL, KPIs y dashboards para generar soluciones de negocio escalables.
5. Desarrollar casos aplicados que integren análisis exploratorio, correlación, feature engineering, MLflow, batch inference y prácticas de MLOps.

### ¿Preguntas sobre Lumi?
1. ¿Cómo puede Lumi Commerce Lakehouse ayudar a centralizar y gobernar los datos del negocio?
2. Qué beneficios aporta una arquitectura Lakehouse frente a un enfoque tradicional de data warehouse?
3. ¿Cómo se implementa la arquitectura Medallion en un caso real dentro de Databricks?
4. ¿Qué papel cumplen Delta Lake y SQL en la confiabilidad y explotación de los datos?
5. ¿Cómo se pueden construir KPIs y dashboards útiles para la toma de decisiones dentro de este ecosistema?

### ¿Preguntas sobre Bagazo?
1. ¿La lluvia es un factor determinante en la baja presentación de caña de azúcar por parte de los ingenios?
2. ¿Existe una relación entre la lluvia y la escasez de bagazo de caña?
3. ¿Qué otras variables, además de la lluvia, podrían estar afectando la disponibilidad de bagazo?
4. ¿Es posible identificar patrones estacionales en la producción de caña y bagazo?
5. ¿Qué tan fuerte es la correlación entre precipitación, cantidad de caña procesada y generación de bagazo?
